🔄 Migração de Fotos: Base64 → Firebase Storage

⚠️ ATENÇÃO - Leia antes de prosseguir:
  • Esta ferramenta converte fotos salvas em base64 para o Firebase Storage
  • O processo é irreversível - as strings base64 serão substituídas por URLs
  • Certifique-se de que o Firebase Storage está configurado
  • Recomenda-se fazer backup antes da migração
  • A migração será feita uma por uma para evitar sobrecarga
✅ Pré-requisitos:
  1. Firebase Storage inicializado (veja guia)
  2. Regras de Storage deployadas (firebase deploy --only storage)
  3. Usuário autenticado no sistema
