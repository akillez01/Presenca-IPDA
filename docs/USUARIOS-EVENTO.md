## 🎯 INSTRUÇÕES PARA O EVENTO

### Preparação:

1. **5 Dispositivos/Tablets:** Configure um dispositivo para cada usuário
2. **Conexão Internet:** Certifique-se de que todos têm internet estável
3. **Teste Prévio:** Faça login com cada usuário antes do evento

### Durante o Evento:

1. **Distribua os Dispositivos:** Posicione os 5 terminais em pontos estratégicos
2. **Login Simultâneo:** Todos os usuários podem fazer login ao mesmo tempo
3. **Registro em Tempo Real:** Todos podem registrar presenças simultaneamente
4. **Sincronização Automática:** Os dados são sincronizados automaticamente

### Monitoramento:

- Todos os registros aparecem em tempo real para todos os usuários
- O sistema suporta registros simultâneos sem conflitos
- Backup automático de todos os dados
