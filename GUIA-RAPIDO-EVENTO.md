## 🎪 DURANTE O EVENTO

### Fluxo de Registro:

1. **Login** → Digite email e senha do terminal
2. **Dashboard** → Acesse "Registrar Presença"
3. **Buscar** → Digite nome da pessoa
4. **Confirmar** → Clique em "Registrar Presença"
5. **Próximo** → Pessoa registrada com sucesso

### Dicas Importantes:

- ✅ Todos os terminais sincronizam automaticamente
- ✅ Se uma pessoa já foi registrada, aparecerá em todos
- ✅ Podem registrar a mesma pessoa em terminais diferentes (sem duplicatas)
- ✅ Relatórios em tempo real disponíveis para todos

## 🆘 RESOLUÇÃO DE PROBLEMAS

### Problema: Login não funciona

**Solução:**

1. Verificar internet
2. Conferir email/senha (copiar exato)
3. Limpar cache do navegador
4. Usar outro terminal como backup

### Problema: Pessoa não aparece na busca

**Solução:**

1. Tentar variações do nome
2. Buscar por sobrenome
3. Verificar se está cadastrada no sistema
4. Registrar como visitante se necessário

### Problema: Sistema lento

**Solução:**

1. Verificar conexão internet
2. Fechar outras aplicações no dispositivo
3. Atualizar página (F5)
4. Redistribuir pessoas entre terminais

### Problema: Terminal travou

**Solução:**

1. Atualizar página (F5)
2. Fazer logout e login novamente
3. Usar outro terminal
4. Reiniciar o dispositivo se necessário
